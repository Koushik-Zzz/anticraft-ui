# Plyxl reference study

These demo sections recreate the visual references supplied from https://plyxl.com/.
The component implementation is original React/CSS. The example copy, Plyxl name,
sheep mark, and integration artwork identify the reference design and its example
workflow; they do not represent a partnership or a live account connection.

- App icon shapes: Solar by 480 Design, https://www.figma.com/community/file/1166831539721848736,
  licensed under CC BY 4.0, https://creativecommons.org/licenses/by/4.0/.
  Nine symbols were extracted from Plyxl's public icon sprite and retain its two-tone styling.
- Integration logos: reference SVG files from https://plyxl.com/logos/.
  Names and marks belong to their respective brands and identify example integrations.
- The small sheep artwork in the agent demo is from Plyxl's public sheep.svg;
  its static face and colored fleece are used for this reference recreation.
- Geist Sans: Vercel / Basement Studio, https://github.com/vercel/geist-font,
  SIL Open Font License 1.1. Font and complete license are in public/fonts/.

The installable components accept your own ReactNode icons, avatars, logos and text.
The demo assets and reference brand artwork are separate from the MIT component code.
