## Responsive verification

For visual changes, verify both the full preview and the embedded component at desktop, tablet, and phone sizes. Include a wide, short desktop viewport (1440 × 650 CSS pixels), a laptop viewport (1366 × 768), and a large desktop (1920 × 1080); read the actual `innerWidth` and `innerHeight` because browser zoom can change the effective size. Check decorative layers, product scaling, horizontal overflow, and native activation of visible controls, including controls reached by scrolling.
